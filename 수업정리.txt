[빌드 & GitHub Pages 배포]
1. GitHub Pages
   ㄴ GitHub Pages는 GitHub에 저장한 HTML, CSS, JavaScript 파일을 인터넷에 공개하여 웹사이트로 실행할 수 있게 해주는 무료 호스팅 서비스.
   GitHub Actions: CI-CD
2. GitHub 저장소(Repository)에 올리고
   GitHub Pages를 설정하면 
   인터넷 주소가 생성
   예)   https://사용자명.github.io/저장소명/
         https://k2nik..github.io/react-practice

3. GitHub Pages의 동작 과정
  1) VS Code에서 웹사이트 개발
     ( HTML · CSS · JavaScript · React ) 
              ↓
  2) GitHub 저장소에 업로드:        "react-practice" 저장소 생성        
     ( 코드를 원격 저장소에 저장 )
              ↓
  3) GitHub Pages 배포
     ( 정적 웹 파일을 웹사이트로 공개 ) 
              ↓
  4) 인터넷에서 웹사이트 접속
     ( Chrome 등 브라우저에서 주소로 접속 )

4. npm run build: dist 폴더에 배포할 파일이 생성
5. 공식 문서: https://docs.github.com/en/pages?utm_source=chatgpt.com

6. "react-practice" 저장소 생성

   저장소 이름을 변경: 변경된 저장소 이름으로 base: 값 설정.

10.  GitHub 배포를 위한 Pages 설정
  1) Settings > Pages > Build and deployment > Source: GitHub Actions로 선택
  2) VS Code  push -> GitHub: 설치, 빌드, 배포(게시) 실행 설정
11. GitHub 자동으로 배포 설정: deploy.yml
  1) 프로젝트 루트에 .github/workflows/deploy.yml
name: Publish React practice

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: true

jobs:
  publish:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.publish.outputs.page_url }}
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-node@v7
        with:
          node-version: '22'
          cache: npm
      - run: npm ci
      - run: npm run build
      - uses: actions/configure-pages@v6
      - uses: actions/upload-pages-artifact@v5
        with:
          path: dist
      - name: Publish
        id: publish
        uses: actions/deploy-pages@v5
